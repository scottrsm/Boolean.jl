# Boolean

[![Build Status](https://github.com/scottrsm/Boolean.jl/actions/workflows/RunTests.yml/badge.svg?branch=main)](https://github.com/scottrsm/Boolean.jl/actions/workflows/RunTests.yml?query=branch%3Amain)

Provides ways to compare two boolean functions.
It uses an internal representation of boolean functions as bit-vectors and 
uses macros to provide a more intuitive external representation.
